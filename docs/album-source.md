# 編集局アルバム

2024・2025・2026年の写真アルバム。フレームワーク不要の静的サイトです。

## プレビュー

このフォルダで実行し、表示されたURLを開きます。

```sh
python3 -m http.server 4173 --directory dist
```

## 写真の追加

公開済みの2024〜2026年の原本写真は、WebPの確認後にローカルから削除しました。サイトの表示・公開には `assets/album.json` と `assets/photos/` のWebPを使います。変換スクリプトは既存の一覧を読み込み、追加写真を統合します。原本がなくなった公開済み写真や、対象外の年度は保持します。既存の一覧・WebPは削除しないでください。

親フォルダに `2024/イベント名/`、`2025/イベント名/`、`2026/イベント名/` の形で写真を配置して、PillowのあるPythonで次を実行します。

```sh
python3 scripts/prepare_photos.py
```

2024・2025・2026年の写真を公開しています。年度を限定して生成する場合は `python3 scripts/prepare_photos.py --years 2026` を使います。

JPEG、PNG、WebP、HEICに対応。HEIC変換にはmacOSの `sips` が必要です。写真がある年度は自動的に閲覧可能になります。未追加の年度は cooming soon と表示されます。

- 原本を変更せず、一覧用（長辺480px）と拡大用（長辺最大1800px）のWebPを生成。拡大用が380KBを超える写真は、長辺1440px・品質70で再生成して容量を抑えます。
- EXIFの向きを反映し、生成ファイルには位置情報などの元メタデータを含めません。
- `dist/assets/album.json` に年度・イベント・画像を追加。再実行しても同じ写真は重複登録しません。変換に失敗した場合は既存の一覧を維持します。
- 元ファイルの内容を同じ名前で差し替えた場合は、対応する生成WebPを削除して再生成してください。
- 不要になった写真のWebPは自動削除されません。完全再生成する場合は `dist/assets/photos/` の生成物を整理してから実行します。

## 操作

トップ → 年度 → イベント → 写真の拡大。拡大中は写真を指でドラッグして移動でき、短いフリックでも前後に切り替わります。前後2枚を先に読み込み、左右キー・大きい左右ボタンにも対応。Escで閉じます。トップには2026年の写真のみを使い、画面全体に広げた5段で左右に流れ、端末の動きを減らす設定に対応。タップして開く年度・イベントのカバー写真はランダムにフェード切り替えします。トップとイベント内の写真は開くたびにランダムな順序になります。写真一覧は60枚ずつ追加表示します。ヘッダーとフッターはなく、紫を基調としています。

## ホスティング

GitHub Pages: https://ytakane102.github.io/

リポジトリ: https://github.com/ytakane102/ytakane102.github.io

`dist/` 内の `index.html`、`style.css`、`app.js`、`assets/` をGitHubリポジトリのルートへコピーして公開しています。`.openai/` は転送しません。既存の `codename/` は保持します。GitHub Pagesは `main` ブランチのルートを公開し、ログイン不要で閲覧できます。

イベント順は2026年が当日、前日準備、装飾・日常、夏合宿、海ドライブ、新歓合宿、運動会。2025年は当日、装飾、前月祭、夏合宿、その他。2024年は当日、装飾、前月祭、夏合宿、夏ドライブ、ディズニー、お別れ会、その他。スマートフォンの高さ変更を伴うスクロールや画面回転では、トップの写真キューを維持します。ランダムな並び直しはトップ画面の表示時に行います。

トップのフォトウォールは2026年の写真だけを表示します。拡大表示の「保存」から、表示中の写真の拡大用WebPを追加圧縮せずダウンロードできます。端末の設定に応じてダウンロード先に保存されます。

「もっと見る」はアルバムを開いたときの写真順を保ち、未表示の写真だけを60枚ずつ固定列の末尾に追加します。最後まで表示するとボタンを隠し、完了メッセージを表示します。

- ギャラリーの追加写真は縦横比から高さを計算し、最も短い列に配置します。既存の写真を動かさず、下部の列の偏りを抑えます。

ブラウザーのタブタイトルは、トップ・年度・イベントの全画面で「編集局アルバム」に統一しています。
